# VRC Consulting – site vitrine

Site d'une page de Valérie Rouch Cornu (VRC Consulting) : conseil et formations en Commerce et en Management.

- `index.html` : page complète (HTML, CSS et JS intégrés), responsive.
- Photo : déposer `valerie.jpg` à la racine puis remplacer le bloc `[PHOTO PORTRAIT HD]` par `<img src="valerie.jpg" alt="Valérie Rouch Cornu">`.
- Formulaire : sans configuration, il ouvre la messagerie du visiteur vers contact@vrc-consulting.fr. Pour un envoi direct, renseigner `FORM_ENDPOINT` (Formspree) en bas de `index.html`.
- Domaine : une fois les DNS de vrc-consulting.fr pointés vers GitHub, ajouter un fichier `CNAME` contenant `vrc-consulting.fr`.
